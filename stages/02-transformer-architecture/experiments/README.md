# Stage 02 — Experiment protocol

Start from [the project template](../../../docs/EXPERIMENT_TEMPLATE.md).

Task targets: Decoder-only model; RoPE/GQA extensions; Cached generation.

For every run record device/framework versions, model/data revisions, dtype, batch, seeds, exact commands, warmup, metric computation and failure conditions.

Never substitute an expected performance estimate for a measured result.
